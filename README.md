## Getting Started

Follow these steps to run the project locally.

### Prerequisites

Install Node.js and npm if the project uses a Node.js-based development environment.

### 1. Clone the repository

```bash
git clone https://github.com/atharvsh5599-droid/atharv-sharma-portfolio.git
```

### 2. Navigate to the project folder

```bash
cd atharv-sharma-portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal, usually:

```text
http://localhost:3000
```

**Note:** These commands assume the repository contains a compatible Node.js project with the corresponding npm scripts. Check `package.json` for the actual framework and available commands.
